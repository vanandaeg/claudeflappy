# Claude Flappy

A Flappy Bird clone built with HTML5 Canvas and vanilla JavaScript. No dependencies, no build step.

## Running the game

Open `index.html` in any modern browser. That's it.

## Controls

- **Space**, **click**, or **tap** — flap / start / restart

## How it works

- `index.html` — page shell and canvas element
- `style.css` — page layout/styling
- `game.js` — all game logic (physics, pipes, collisions, scoring, rendering)

Best score is saved locally in your browser via `localStorage`.
